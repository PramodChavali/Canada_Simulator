# Canada_Simulator
 
This was my final project for Grade 11 Computer Science (I got 100% :])
It was made using tkinter in python, and creating this project made me realize the joy that I find in game development!
I hope you enjoy this silly little game, and let me know somehow if you score an A+! This is when ALL of the tiles are clean by the time dad gets home, I know it's possible, but I haven't gotten it yet (I have come very close though).

Dad has to myseteriously leave, so you better keep the driveway clean till he gets back!
